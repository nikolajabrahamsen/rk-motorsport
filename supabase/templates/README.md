# Danske mailskabeloner (med kode i stedet for link)

Indsæt i Supabase → Authentication → Emails → Templates.

| Skabelon i Supabase | Emne | Fil |
|---|---|---|
| Reset Password | Din kode til ny adgangskode | recovery.html |
| Change Email Address | Bekræft din nye mail | email_change.html |

Kopiér hele indholdet af filen ind i feltet "Message body" (Source) og gem.

"Confirm email" skal fortsat være slået fra – nye brugere godkendes af teamchefen i appen.
